# 🔐 Password Generator

A simple, lightweight, and responsive **Password Generator** built with HTML, CSS, and JavaScript.

The application allows users to generate random passwords with customizable lengths and character types, copy generated passwords to the clipboard, and view an estimated password strength.

---

## ✨ Features

- 🔐 Generate random passwords
- 📏 Choose password length
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include symbols
- 📋 Copy generated passwords to the clipboard
- 💪 Password strength indicator
- 🟢 Strong / 🟡 Medium / 🔴 Weak strength levels
- ⚡ Fast and lightweight
- 📱 Responsive design
- 🎨 Clean and modern interface
- 🚫 No backend required
- 🔒 Password generation happens locally in the browser

---

## 🖥️ Preview

The application provides a simple interface containing:

- A generated password field
- A copy-to-clipboard button
- A password length slider
- Character-type options
- A **Generate Password** button
- A password strength meter

This project uses standard front-end web technologies:
